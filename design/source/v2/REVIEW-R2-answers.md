## 브리프 P0 답
1. **버튼이 내용을 가림**: 하단 **좌대 막대**(PlinthBar)로 풉니다. 높이 `--plinth-h` 128, 바탕 `--fade-plinth`, 스크롤 끝 여백도 같은 값입니다. → System VIII
2. **아이콘만 있는 버튼**: 아이콘만 쓰는 방식(I2)은 유지합니다. 대신 두 가지를 더합니다.
   - 길게 누르면 이름 말풍선이 뜹니다(400ms 뒤에 떠서 1.5초 유지).
   - 앱 고유 동작(입장권·카드·고정)은 처음 한 번 하늘색 안내가 뜹니다.
   - 첫 실행 화면을 포함해 모든 버튼에 글자를 쓰지 않습니다(v2.2). → System IV
3. **글자 규칙**: 글꼴마다 맡는 일을 하나로 정합니다.
   - serif: 이름(화면·컬렉션·오브제·시트 제목, 노트)
   - sans: 조작과 설명
   - mono: 기록된 값만
   - roman: 고전 표기
   - 한글 + 모노 + 넓은 자간 라벨은 없앱니다. 목록 제목은 19px 한 줄로 쓰고 넘치면 말줄임합니다. → System II
4. **버튼 표면**: I3 단색 표면을 승인하고 `--glass-*`는 모두 지웁니다.
   - 모든 버튼은 바탕 없는 하늘 이중 원 + 하늘 아이콘(대비 7.4:1, 연하늘 위 짙은 글자 문제 해결). 확인 = check(오른쪽), 취소 = close(왼쪽).
   - 사진 위 버튼은 흰 1px 테두리 + 흰 아이콘.
5. **위험 색**: 색으로 구분하지 않음(v2.2). 휴지통 아이콘 + 지워지는 것을 숫자로 보여 주는 확인 시트. `--danger` 계열은 남기되 쓰지 않음.
6. **빈 상태**
   - A1 첫 실행
   - B1 빈 컬렉션: 점선 좌대 + "N° 01"
   - 빈 표지: 신전 심볼
   - 빈 노트: D3

## 새로 제안하는 것 (단계 2로 구현 가능)
- **컬렉션 ⋯ 시트** (B4): 이름·장소 고치기 / 컬렉션 마무리 / 폴더로 / 고정 / 지우기
- **마무리 상태** (B3): "마무리" 알약에 seal 아이콘. 하단 주 버튼이 입장권으로 바뀌고, +는 ⋯ 안 "다시 모으기"로 옮긴다
- **홈 검색·정렬** (A2): 위 오른쪽 search·sort. 정렬은 최근 추가 / 이름 / 오브제 수
- **Toast 자리**: 하단 버튼 줄 바로 위에 고정하고 어두운 바탕(`--toast-bg`)을 쓴다. 오래 걸리는 일은 점 세 개가 흐르게. 지우기 뒤에는 "되돌리기"를 4초 동안 보인다
- **사진 보기** (D6): 좌우로 넘기기, 위 가운데 "04 / 04", ⓘ로 캡션
- **캡션 카드** (D2): OCR 원문을 첫 줄(제목) / 작가 / 표(재료·크기·연도)로 나눠 보여 준다. 나누기에 실패하면 원문 그대로. 읽는 중에는 줄 자리 표시 + "글자 읽는 중"
- **카드 노트 길이**: 16 → 15 → 14px로 줄이고, 그래도 넘치면 8줄 뒤에서 말줄임
- **다크 모드**: 이번에는 만들지 않는다
