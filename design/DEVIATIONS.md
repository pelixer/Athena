# 디자인 이탈 기록

시안과 다르게 구현한 부분. 형식: 화면/컴포넌트 · 시안 · 구현 · 이유

## v2.3 "Stoa" (2026-10-23)

- **지우기 색**: B4 ⋯ 시트의 "컬렉션 지우기" 줄과 B5의 DELETE 눈썹이 시안에서는 테라코타지만, README·R2 답변은 "위험 색은 쓰지 않는다"고 한다. README를 따라 먹·돌 색으로 두었다.
- **아이콘 파일**: 묶음의 `icons/*.svg`는 옛 규칙(1.5 선, square 끝, 하늘 점)이었다. System 페이지의 v2.3 인라인 SVG를 기준으로 `design/icons/`를 다시 그렸고 `Icon.tsx`도 같다.
- **토큰 파일 머리**: `tokens.css` 머리말은 v2.1, README는 v2.3. 값은 README·System과 맞으니 그대로 옮겼다.
- **4pt 밖 값**: README의 "픽셀 단위로 맞춰 주세요"에 따라 시안 수치(22, 26, 14, 10, 18 등)를 컴포넌트 CSS에 그대로 썼다. v0 때 4pt로 바꿨던 간격(아래 표)도 이제 시안 값이다.
- **음각 글자색** `#5F5C56`: 토큰이 없어(README §6에 값만 있음) `Card.module.css`에 그대로 썼다. `--engrave` 그림자는 토큰.
- **카드 서명 메타**: 장소가 길면 시안처럼 두 줄을 지키도록 줄마다 말줄임 (R3 승인). 밑선 맞춤은 시안의 `margin-bottom: calc(-0.275em - 0.7px)` 대신 기준선 정렬로 했다.
- **지우기 색**·**카드 서명 말줄임**은 R3에서 승인됨.
- **오브제 좌표**: 시안 D1에는 날짜·장소 두 줄뿐. 장소 이름이 없을 때만 좌표 줄을 보인다.
- **카메라를 열 수 없음(C4)**: 시안대로 아래 셔터 줄 없이 심볼 · 안내 · 사진 버튼만.
- **입장권 크기**: 시안 미리보기 300×533을 실제 크기로 쓰고 3.6배로 내보낸다(1080×1920). 그림자는 내보낼 때 뺀다.

### 레이아웃 — 고정 프레임 → 실제 기기
- 시안은 390×844 프레임 안의 절대 좌표. 구현은 기기 안전 영역(`--safe-top`, `--safe-bottom`) 기준으로 위 버튼 줄과 아래 버튼 줄을 고정하고 본문은 흐르게 했다. 시안의 "상단 56"은 상태바 44 + 12로 해석했다.
- 오브제 상세 사진 높이: 460 → `min(460px, 56dvh)` (작은 화면에서 본문이 보이게).
- 공유 카드 화면: 절대 위치 대신 세로로 쌓았다(카드 → 스타일 → 항목 칩).
- 관람 보기 제목: 시안의 수동 줄바꿈(`흰 절벽 —<br>`) 대신 어절 단위 자동 줄바꿈(`word-break: keep-all`, `text-wrap: balance`).

### 기능 차이
- 관람 보기 오른쪽 위 ↗: 갈 곳(템플릿)이 없어 뺐다 (REVIEW R8).
- 도슨트 텍스트 자동 추출(OCR): 서버 없이 기기 안에서 읽는다 — 2026-10-18부터 PaddleOCR PP-OCRv5(한국어·영어) 주 엔진, Tesseract 예비. 사진은 바로 붙고 글자는 1~수 초 뒤에 채워진다. 정확도가 완벽하지 않아 DocentBlock에 "고치기"를 더했다 (REVIEW R10).
- 오브제 상세의 ↗: 카드 만들기로 연결했다.

### 글꼴
- Monoplex KR(v1.1.0, 400/500/600)과 Pretendard(가변)를 앱에 내장했다. 시안은 CDN에서 받는다. 굵기와 모양은 같고, 오프라인에서도 같게 보인다.

## 2026-10-18

- 도슨트 고치기의 첫 줄 입력칸(R10, `--type-heading-s` 15px) · 글자 크기만 16px. iOS가 16px보다 작은 입력칸에 초점이 가면 화면을 확대해 버린다.

## 2026-10-18 · 사용자 요청
- **하단 버튼 글자 제거 (I2)** — 시안의 54 높이 글자+아이콘 알약 버튼을 54 원형 아이콘 버튼으로 바꿨다. 사용자 의도: "텍스트 없는 아이콘만 있는 버튼". 폭이 줄어 두 버튼을 가운데로 모았다.
- **촬영 화면 배치 (R13·R14)** — 시안: [썸네일 | 셔터 | 전환], 위 가운데 관람 알약 + 오른쪽 순번 배지. 구현: [사진 고르기·첨부 취소 | 셔터 | 썸네일], 전환은 위 오른쪽, 순번은 위 가운데 안내 문구 안으로("다음 No.08"). 카메라를 못 열 때의 Toast는 없앴다.
- **사진 고르기** — 파일 입력의 `capture="environment"`를 뺐다. 붙어 있으면 휴대폰이 카메라만 열어서 사진첩을 고를 수 없었다.
- **새 관람 시작 → 관람 보기** — 시작하면 바로 촬영으로 가던 흐름을 관람 보기(VisitPage)로 바꿨다. 촬영은 관람 보기의 + 버튼에서.
- **오브제 상세 위 오른쪽 카드 버튼 제거** — 하단 카드 버튼과 겹쳐 하나만 남겼다.
- **아이콘·버튼 표면 (I3)** — 안 C의 둥근 끝·곡선을 90° 꺾임으로, 유리 그라데이션 표면을 단색으로. 값은 기존 토큰만 썼다.
- **나의 노트 자리 (R15)**, **촬영 화면 정리 (R16)** — 하단 시각·장소·좌표 표시는 화면에서만 뺐고, 기록(오브제의 시각·좌표 저장)은 그대로다.
- **도슨트 → 캡션 (C1)** — 화면 글자만 바꿨다. 코드·데이터 이름은 `docent` 그대로 (저장된 데이터와 호환).
- **첨부 흐름 (R13 개정)**, **프레임 통일 (R17)**, **저장 확인 시트 (R18)** — 사용자 피드백으로 바꿨다. 이유는 REVIEW 항목에.
- **캡션이 붙는 오브제** — "가장 최근에 찍은(촬영 시각)" 오브제에서 "가장 최근에 추가한" 오브제로. 사진첩에서 올린 예전 사진은 촬영 시각이 과거라 엉뚱한 오브제에 캡션이 붙고 썸네일도 예전 오브제를 보였다.
- **페이지 확대·축소 막음** — iPhone에서 핀치로 화면 전체가 줄어든 채 남는 문제(Safari는 viewport의 user-scalable=no를 무시). viewport `minimum-scale=1, maximum-scale=1`, `touch-action: pan-x pan-y`, Safari `gesture*` 이벤트 차단. 사진 크게 보기는 PhotoViewer 자체 핀치로 그대로 된다. 접근성(글자 확대)은 기기 글자 크기 설정에 맡긴다.
- **컨셉 확장 (C2)** — 화면 말만 바꿨다. 코드·데이터 이름 `Visit`은 그대로.
