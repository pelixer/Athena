### 레이아웃 — 고정 프레임 → 실제 기기
- 시안은 390×844 프레임 안의 절대 좌표. 구현은 기기 안전 영역(`--safe-top`, `--safe-bottom`) 기준으로 위 버튼 줄과 아래 버튼 줄을 고정하고 본문은 흐르게 했다. 시안의 "상단 56"은 상태바 44 + 12로 해석했다.
- 오브제 상세 사진 높이: 460 → `min(460px, 56dvh)` (작은 화면에서 본문이 보이게).
- 공유 카드 화면: 절대 위치 대신 세로로 쌓았다(카드 → 스타일 → 항목 칩).
- 관람 보기 제목: 시안의 수동 줄바꿈(`흰 절벽 —<br>`) 대신 어절 단위 자동 줄바꿈(`word-break: keep-all`, `text-wrap: balance`).

### 기능 차이
- 관람 보기 오른쪽 위 ↗: 갈 곳(템플릿)이 없어 뺐다 (REVIEW R8).
- 도슨트 텍스트 자동 추출(OCR): 서버 없이 기기 안에서 Tesseract(한국어 정밀 모델)로 읽는다. 사진은 바로 붙고 글자는 1~수 초 뒤에 채워진다. 정확도가 완벽하지 않아 DocentBlock에 "고치기"를 더했다 (REVIEW R10).
- 오브제 상세의 ↗: 카드 만들기로 연결했다.

### 글꼴
- Monoplex KR(v1.1.0, 400/500/600)과 Pretendard(가변)를 앱에 내장했다. 시안은 CDN에서 받는다. 굵기와 모양은 같고, 오프라인에서도 같게 보인다.

## 2026-10-18

- 도슨트 고치기의 첫 줄 입력칸(R10, `--type-heading-s` 15px) · 글자 크기만 16px. iOS가 16px보다 작은 입력칸에 초점이 가면 화면을 확대해 버린다.
