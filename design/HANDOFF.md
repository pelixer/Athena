# Claude Design ↔ Claude Code 핸드오프

Claude Design에 이 파일, `design/tokens.css`, `docs/CONCEPT.md`, `design/references/`를 함께 준다.

## Claude Design에게 부탁하는 것
1. **값은 `design/tokens.css`의 토큰 이름으로.** 지금 값은 레퍼런스 사진에서 뽑은 임시값(v0-draft)이다.
   새 토큰이 필요하면 이름과 용도를 함께 제안한다 (예: `--color-overlay` — 사진 위 텍스트 배경).
2. **화면과 컴포넌트는 아래 이름으로.** 디자인 안의 레이어/프레임 이름도 같게 해주면 코멘트가 바로 코드로 이어진다.
3. **산출물은 아티팩트 링크로.** 링크를 Claude Code에 주면 직접 읽어서 구현한다.
4. 구현 결과는 컴포넌트 갤러리 링크로 돌아온다. 피드백은 그 위에 코멘트로.

## 화면 (v0 범위)

| 화면 | 코드 | 경로 | 내용 |
|---|---|---|---|
| 촬영 | `CapturePage` | `/visit/:id/capture` | 오브제 사진, 도슨트 사진/텍스트, #라벨, 나의 노트 |
| 오브제 상세 | `ObjePage` | `/obje/:id` | 사진, MetaLine, 라벨, 도슨트, 나의 노트, 카드 만들기 |
| 관람 보기 | `VisitPage` | `/visit/:id` | 관람 제목·날짜, 오브제 그리드(순번), 오브제 추가, 관람 마치기 |
| 공유 카드 | `ShareCardPage` | `/obje/:id/card` | ShareCard 미리보기 (이미지 저장·공유는 다음 단계) |
| (홈) | `HomePage` | `/` | 관람 목록, 새 관람 시작 |

관람 보기는 **조회 화면**이다. 템플릿(관람을 마치며 만드는 산출물)과는 다른 화면으로 디자인한다.

## 컴포넌트

| 컴포넌트 | 쓰이는 곳 | 메모 |
|---|---|---|
| `Page` | 모든 화면 | 상단 제목 + 뒤로 |
| `Button` | 전역 | `primary` / `ghost` |
| `TagChip`, `TagList` | 촬영, 오브제 상세 | `#라벨` |
| `MetaLine` | 오브제 상세 | 날짜 · 시각 · 순번(No. 07) · 위치 |
| `ObjeThumb` | 관람 보기 | 사진 + 순번 |
| `DocentBlock` | 오브제 상세 | 현장 설명문 = 기록 |
| `NoteBlock` | 오브제 상세 | 나의 해석 = 해석. 기록과 구분되지만 나란히 |
| `ShareCard` | 공유 카드 | 9:16. 이 DOM이 그대로 이미지가 된다 → 웹폰트·CSS로 표현 가능한 범위에서 |
