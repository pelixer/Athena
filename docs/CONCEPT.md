# Athena — 컨셉 노트 (v0)

> 세부 기능·페이지는 미정. 여기에는 지금까지 합의된 컨셉만 기록한다.

## 한 줄 정의
미술관·전시·콘서트, 혹은 일상 속에서 마주친 **오브제**를 사진으로 담고,
`#라벨`과 나만의 해석을 붙여 보관하고, 예쁜 카드와 템플릿으로 남기는 웹앱.

## 핵심 개념 (용어집 — 디자인과 코드가 같은 이름을 쓴다)

| 용어 | 코드 이름 | 정의 |
|---|---|---|
| 오브제 | `Obje` | 사진 한 장으로 기록되는 대상. 미술작품, 전시, 설치미술, 셀카, 일상의 물건, 날씨 등 무엇이든. |
| 라벨 | `Tag` | `#`으로 시작하는 라벨. 오브제에 여러 개 붙는다. (예: `#데이비드호크니` `#다이빙`) |
| 도슨트 | `Docent` | 현장 설명문을 찍은 사진에서 텍스트를 추출(OCR)한 원문. 오브제 옆에 붙는다. |
| 나의 노트 | `Note` | 나만의 도슨트, 감정, 해석. 오브제에 붙는다. |
| 관람 | `Visit` | 하나의 전시/공연/하루 경험. 오브제들의 묶음. 장소·날짜를 가진다. |
| 순번 | `Visit.index` | 그 관람 동안 몇 번째로 찍은 사진인지. |
| 카드 | `ShareCard` | 오브제 + 날짜 + 내 해석 등을 얹어 만든 공유용 이미지 (Spotify 가사 공유 카드 같은 형태). |
| 템플릿 | `Template` | 관람 하나를 마무리하며 만드는 **산출물**. |

## 무드
순수하고 하얀 대리석, 그리고 맑은 하늘의 파랑. 미술관에 가면 늘 있는 고전 조각상 같은 느낌.
레퍼런스 사진: `design/references/` (백악 절벽과 하늘, 절벽과 바다, 흰 대리석)

## 원칙
1. **템플릿은 산출물이지 조회의 프레임이 아니다.** 템플릿은 관람 경험을 내보내는 결과물이고,
   오브제·관람을 조회하는 페이지는 템플릿과 무관하게 고유한 화면으로 존재한다.
2. 오브제마다 시간, 위치, 관람 내 순번이 자동으로 기록된다.
3. 기록(사진·도슨트)과 해석(나의 노트)은 구분되지만 나란히 놓인다.

## 시나리오 예시
국립현대미술관에서 데이비드 호크니의 다이빙 그림을 찍는다 → 옆의 도슨트 설명문도 찍으면
텍스트가 추출되어 오브제 옆에 붙는다 → 그 자리에서 나의 감정·해석을 적는다 →
전시를 다 보고 나면 나만의 템플릿으로 이 관람을 저장한다 → 마음에 드는 오브제는 카드로 만들어 공유한다.
